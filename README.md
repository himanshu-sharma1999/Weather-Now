# Weather Now 🌦️

A simple real-time weather app that shows the current weather for any city entered.

## 🚀 Features
- Search weather for any city
- Displays temperature, weather condition, humidity, and wind speed
- Fetches data using OpenWeatherMap API
- Responsive and simple UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 🧪 Run Locally
1. Open `index.html` file in your browser
2. Enter any city name to see the current weather
